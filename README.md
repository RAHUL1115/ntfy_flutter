# ntfy Flutter

Minimal Android Flutter scaffold for a new ntfy client inspired by the official native Android app.

The source-aligned shell, local subscriptions and cleanup, foreground topic feeds, and common-field publishing are implemented; background delivery and the remaining MVP behavior are tracked in GitHub issues. See [the MVP specification](docs/android-first-mvp-spec.md).

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```
